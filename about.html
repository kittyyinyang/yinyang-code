方法论

这一页记录这套编码是怎么被数据纠出来的，以及哪些部分还没被验证。 判断依据与反例同等重要。

一、唯一锚点

1 · 阳 价值感自己给的　 0 · 阴 价值感要别人给的

除这一条外，编码器不持有任何「阴阳含义」。其余全部由规则推导。

二、分层

层内容状态
L1八卦：三爻人格码（内核 / 性别 / 外显）结构自洽
L2外显能量：三爻加权 r = 4·初 + 2·二 + 1·三对齐先天八卦次序
L3难度 = |偏离|，0–3三爻权重天然给出
L1.5维度层：规训集，破壳 = 删训强度标定进行中
L464 卦：下卦 = 我，上卦 = 对方因果读法已实证
L4·场非人格的场（社会 / 集体意识）⚠️ 推演，无语料支撑

三、实证 vs 推演

实证 有语料或样本支撑

  • 三爻人格码 8/8 自洽
  • 64 卦名 64/64 对齐标准表
  • 代际传递：因果读法，2 个家庭实证
  • 壳的代际来源
  • 破壳路径：1 个完整样本

推演 尚无支撑

  • 非人格「场」的三爻编码
  • 父母要求相反时谁胜出（仅 1 例）
  • 规训强度 0–3 的标定（单样本）
  • 子女的反向 64 卦（亲子教育场景）

四、判据：可观测，不可语感

LLM 只做特征抽取，编码规则做判定。 绝不让人（或模型）直接判断「这个人是阴是阳」——那正是「在相上打转」。

判据只问可观测行为，例如 「出了问题第一反应是『我哪里没做好』还是『谁对不起我』」。

四条被禁用的判据

它们在阴阳两边都会高频出现，没有判别力：

  • 谁做决定
  • 谁扛事 （男阴的扛事可能正是壳）
  • 是否强势 / 能忍 / 不求助
  • 使命感强弱

六、红线

  1. 卦爻辞不作论据。卦名只作索引标签。
  2. 不让 LLM 直接判阴阳。只做特征抽取。
  3. 跑词频前先抽样确认作者实际用语，不得套用通用词族。
  4. 被数据纠错时必须承认，不得维护先前判断。
  5. 推演层与实证层分开标注，不得混用。
  6. 不做医学诊断、治疗或疗效宣称。身心现象仅作事实记录。
