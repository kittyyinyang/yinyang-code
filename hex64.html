64 卦关系矩阵

一个人是 3 bit，一段关系是 6 bit。下卦 = 我，上卦 = 对方。

上卦不是新维度，是另一个人的完整卦码

父母 / 伴侣 / 子女本身就是一个人 → 本身就是一个卦 → 三爻语义与下卦完全同构，不需要另发明维度。

位bit下卦（我）上卦（对方）
初爻bit0 / bit3我的内核对方的内核 = 他对我的要求
二爻bit1 / bit4我的性别对方的性别
三爻bit2 / bit5我的外显对方的外显 = 他对我的方式

⚠️ 只有「非人格的场」是推演层

社会 / 集体意识 / 时代不是一个「人」，没有内核与性别。 此时上卦退化为只用外显一爻（bit5），bit3 / bit4 恒 0。 这部分尚无语料支撑，标记为推演。

错卦对：四对经典综卦

阴阳完全相反的两个人，其双视角恰好落在四对经典综卦上：

人格配对我的视角码对方的视角码

综卦 = 同一段关系的两个视角。 你这边看是 A 卦，对方那边看是它的综卦——同一段关系，两个人住在不同的卦里。
