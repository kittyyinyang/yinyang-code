# 阴阳人格 · 编码体系

> 把阴阳编译成 0 和 1，让下游（人 / AI / 产品）只对位运算做推演。
> 语义只有一个锚点，其余全部由规则推导。

## 唯一语义锚点

| | |
|---|---|
| **1 · 阳** | 价值感**自己给的** |
| **0 · 阴** | 价值感**要别人给的** |

除这一条外，编码器不持有任何「阴阳含义」。

## 编码

### 一个人 = 3 bit

| 爻 | bit | 含义 | 权重 |
|---|---|---|---|
| 初爻 | bit0 | 本源能量（内核） | 4 |
| 二爻 | bit1 | 性别（1 男 / 0 女） | 2 |
| 三爻 | bit2 | 外显（真显 or 壳） | 1 |

`卦码 = 初爻×1 + 二爻×2 + 三爻×4`（标准莱布尼茨序，0–7）

坤0 震1 坎2 兑3 艮4 离5 巽6 乾7

**内核只由初爻决定**（二值）；**外显能量**是三爻加权：

```
r = 初爻×4 + 二爻×2 + 三爻×1        （0–7）
外显阳能量% = r / 7 × 100
先天序 = 8 − r
```

该加权序与先天（伏羲）八卦次序一致：乾1 兑2 离3 震4 巽5 坎6 艮7 坤8。

### 难度 = |偏离|（0–3）

乾0 兑1 离2 **震3** **巽3** 坎2 艮1 坤0

震 / 巽 最难：性别与壳**同向叠加**，剥壳之后性别关还在原地，且没有社会奖励。

### 一段关系 = 6 bit（64 卦）

`卦码 = 下卦(我) | 上卦(对方) << 3`

**上卦 = 对方的完整卦码**，与下卦三爻同构：

| 位 | 下卦（我） | 上卦（对方） |
|---|---|---|
| 初爻 | 我的内核 | 对方的内核 = **他对我的要求** |
| 二爻 | 我的性别 | 对方的性别 |
| 三爻 | 我的外显 | 对方的外显 = **他对我的方式** |

父母 / 伴侣 / 子女本身就是一个人 → 本身就是一个卦 → 不需要为上卦另发明维度。

⚠️ 只有「非人格的场」（社会 / 集体意识）是推演层，退化为只用外显一爻。

## 代际传递

父母向子女传递**两个东西**，方向可以相反：

- **方式**（他怎么对你）= 父母**外显**
- **要求**（他要你成为什么）= 父母**内核**

**壳由「要求」决定，不由「方式」决定。**

撕裂的真正来源：父母**自身带壳** → 外显 ≠ 内核 → 方式与要求方向相反 → 矛盾指令。

```
家庭撕裂度 = 带壳(父) + 带壳(母)     （0–2）
```

## 破壳 = 删训

每一条训：`{ 来源, 方向(1要你显阳 / 0要你显阴), 强度 0–3 }`

- 与内核**反向**的训撑住壳；与内核**同向**的训撑住真身
- **壳 = 反向合力 > 同向合力**
- 性别脚本训由二爻派生，强度**固定 2**，**不可删除，只能超越**
- 按强度降序解除训，卦码**自动翻转** —— 剥壳归真是删训的结果，不是额外规则

## 红线

1. 卦爻辞不作论据，卦名只作索引标签
2. 不让 LLM 直接判阴阳，只做特征抽取
3. 跑词频前先抽样确认作者实际用语
4. 被数据纠错时必须承认
5. 推演层与实证层分开标注
6. 不做医学诊断、治疗或疗效宣称

理论与编码体系为原创，语料引自公开视频并标注出处。
