破壳路径

破壳不是「改三爻」，是解除规训——三爻会自己翻过来。 这一层把「我要改变」翻译成「我要解除哪几条训」。

规训集：壳是怎么被撑住的

每一条训有四个字段：

训 = { 来源, 方向(1要你显阳 / 0要你显阴), 强度 0–3 }

两条规则

· 与内核反向的训撑住壳
· 与内核同向的训撑住真身
壳 = 反向合力 > 同向合力

性别脚本训是特殊的

它由二爻派生，强度固定为 2。
它不可删除，只能超越。
这就是为什么「女 + 阳内核」天然就要多打一仗。

破壳 = 按强度降序解除训，直到卦码翻转

不需要「决定要变成什么样」。训解除够了，外显自动归位。 剥壳归真 是删训的结果，不是额外规则。

两条硬结论

① 只解除最大的那一股，不够

示例里解除母训（强度 3）之后仍在壳中， 必须再解除父训（强度 2）才翻转。
破壳有临界点——不是「想通了一件大事」就好了。

② 人不在了，训还在

示例中父亲很早就离世，但他的训强度仍是 2， 并且是翻转的必要条件。
规训活在心里，不活在那个人的在场与否。

要不要写进产品文案

难度 3（震 / 巽）的人，破壳要打两仗，而且第二仗没有社会奖励—— 剥壳之后性别关还在原地。
这一条必须原样告诉用户。否则用户会在「壳剥了却还是难受」时以为自己失败。
