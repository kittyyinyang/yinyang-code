代际传递规则

父母向子女传递两个东西，方向可以相反

传递物来源含义编在哪个爻
方式父母的外显（三爻）他怎么对你上卦三爻 = bit5
要求父母的内核（初爻）他要你成为什么上卦初爻 = bit3

壳由「要求」决定，不由「方式」决定。

⚠️ 这条规则是被数据纠出来的

v1 曾写「传递物 = 父母外显」。用实际数据检验时被证伪：

某家庭父母外显都是阳，v1 据此预测传递「阳」； 但当事人实际继承的是阴（不能锋芒太露 / 要乖 / 要收 / 多牺牲 / 多考虑他们）。
→ v1 错。真实机制是两个传递物，且方向可以相反。

撕裂的真正来源

当父母自己带壳时，外显 ≠ 内核 → 方式与要求方向相反 → 向子女发出矛盾指令。
这就是「怎么做都不对」的来源。

撕裂度(父母) = 带壳 ? 1 : 0
家庭撕裂度 = 撕裂度(父) + 撕裂度(母)      （0–2）

难度衡量的是撕裂，不是痛苦

难度低 ≠ 过得好。它只说明内外不打架。
